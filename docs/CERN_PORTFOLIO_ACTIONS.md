## Publication quality gates

Each featured repository should have:
1. Accurate README with problem, scope, current status and your contribution.
2. Reproducible setup with dependency versions.
3. Technical architecture diagram and organized source.
4. Real media or plots when available.
5. Evidence-backed results, including failures and limitations.
6. Appropriate attribution, permissions and license decisions.
7. No secrets, API tokens, private customer data or proprietary employer files.
